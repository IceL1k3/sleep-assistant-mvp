# Biofeedback Sleep Assistant MVP

Интеллектуальная адаптивная система генерации персонализированного аудиопотока на основе биосигналов пользователя в замкнутом контуре (Biofeedback Audio System). Проект ориентирован на R&D (Research and Development) в сфере цифровой обработки сигналов (DSP) и генеративного искусственного интеллекта.

---

## 🧠 Архитектура и ключевые модули системы

Система построена на принципах мультимодальности и динамического управления на основе обратной связи:

1. **Точка входа и оркестрация (LLM):** 
   - Пользователь отправляет текстовый промпт с описанием желаемой атмосферы или загружает собственный аудио-референс.
   - Локальный ИИ-Оркестратор на базе компактной языковой модели **Qwen-2.5** запускается однократно на старте, выполняет векторизацию стиля (извлечение тембральных, спектральных признаков и тональности через `Librosa` / вейвлет-анализ `CWT`) и формирует базовый неизменяемый промпт-шаблон для генератора, после чего отключается для экономии ресурсов ЦНС и процессора.

2. **Пошаговая генерация (Audio Continuation):**
   - Вместо генерации длинных тяжелых аудиофайлов, музыкальная нейросеть генерирует поток короткими кусками по 15–20 секунд.
   - Для обеспечения бесшовности и исключения эффекта раздражающего "белого шума", каждый последующий фрагмент синтезируется на основе последних 3 секунд аудиоконтекста предыдущего отрезка.

3. **Био-регуляция в реальном времени (1D-CNN + ВСР):**
   - Одномерная сверточная нейросеть (**1D-CNN**) каждые 15–20 секунд анализирует поступающий с носимого устройства временной ряд вариабельности сердечного ритма (ВСР).
   - Модель рассчитывает числовой коэффициент расслабления ЦНС, который на ходу меняет параметры генерации музыки (делает её более предсказуемой, монотонной и убирает хаотичность по мере засыпания).
   - Если 1D-CNN фиксирует переход пользователя в устойчивую фазу сна, система полностью останавливает генерацию до истечения основного таймера.

4. **Локальный DSP-фильтр:**
   - Модуль обработки сигналов на стороне приложения локально сглаживает пиковые всплески громкости, а также реализует плавный алгоритмический Fade-Out (частотный срез верхнего регистра и плавное затухание амплитуды до нуля).

## 🛠️ Технологический стек проекта

- **Язык разработки:** Python
- **Обработка сигналов и вейвлет-анализ:** SciPy (Signal), Librosa, PyWavelets
- **Нейросетевое ядро (AI/ML):** PyTorch (1D-CNN), Qwen-2.5-3B-Instruct (LLM-агент)
- **Аудио-движок:** AudioCraft / AudioGen (Meta) или кастомный процедурный синтез звука
- **Управление данными:** NumPy, Pandas

## 📈 План разработки MVP (Roadmap)

- [ ] **Этап 1:** Сбор открытых медицинских датасетов ВСР (PhysioNet) и препроцессинг зашумленных данных.
- [ ] **Этап 2:** Проектирование и обучение 1D-CNN для классификации фаз засыпания.
- [ ] **Этап 3:** Разработка модуля анализа аудио-референсов с извлечением спектральных фич через Librosa.
- [ ] **Этап 4:** Настройка локального аудио-движка с пошаговым механизмом продолжения контекста (Continuation).
- [ ] **Этап 5:** Реализация законов связи коэффициента ВСР с параметрами генерации и финальная сборка пайплайна.
